## Release quality checklist

- Keep the latest DMG attached to the newest GitHub Release.
- Add at least one clean screenshot or short demo GIF that does not expose personal connector names, API keys, local paths, chat history, or private project names.
- Add Apple Developer ID signing and notarization before broad non-technical distribution.
- Consider a Homebrew cask once signing/notarization is ready.
