你正在运行 `doc-generator` 技能。

## 目标
基于用户指定的代码、配置、目录或主题，生成清晰、可维护、适合长期保存的文档。

## 输入
- 目标：`{{target}}`
- 文档类型：`{{doc_type}}`

## 工作流
1. 先确认文档要解决的读者问题：安装、使用、维护、排障、长期知识沉淀。
2. 读取最关键的 1-4 个文件；范围不明确时先 `code_search` 定位入口、配置、测试和现有文档。
3. 不要编造 API、命令或配置项；所有具体命令和路径必须来自工具结果或明确标注为建议。
4. 根据 `{{doc_type}}` 生成对应结构：
   - README：简介、安装、快速开始、配置、常用命令、故障排查。
   - API：接口、参数、返回值、错误、示例。
   - 使用指南：场景、步骤、示例、注意事项。
   - Wiki：概念、背景、实践、关联链接。
5. 用户要求写入文件时，优先精准编辑已有文件；新文件才全量写入。
6. 写入后读取目标文件或运行合适验证命令，确认文档内容落盘。

## 输出格式
- **结果**：已生成/已更新/仅预览。
- **建议路径**：推荐或实际保存位置。
- **文档草稿**：完整 Markdown 内容或变更摘要。
- **依据**：列出参考的关键文件、配置或笔记。
- **验证**：写入/构建/未验证原因。
