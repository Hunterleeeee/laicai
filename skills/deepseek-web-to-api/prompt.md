## 规则
1. 优先推荐 DeepSeek 官方 API 或用户已有的合法 API 凭证；不要帮助绕过登录、验证码、风控、付费限制或服务条款。

3. 如果用户提供的是网页端聊天链接，输出“可迁移方案”：如何把需求迁移到官方 API、如何整理历史对话、如何设计本地代理接口。
4. 根据模式生成安全输出：

   - **proxy_service**：生成本地 FastAPI/Flask 代理骨架，只转发到官方/用户授权端点，包含超时、错误处理和日志脱敏。
   - **migration_plan**：给出从网页工作流迁移到 API 的步骤。
5. 生成的代码必须标明需要用户配置的环境变量，不在代码里硬编码密钥、Cookie 或账号信息。
6. 如果公开页面无法获取有效信息，说明限制并给出合规替代路径。
7. 保存到 Obsidian 时只保存方案、代码模板和配置说明，不保存敏感信息。
