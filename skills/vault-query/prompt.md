你正在运行 `vault-query` 技能。

## 目标
在用户的 Obsidian Vault / 本地知识库中查找与主题相关的笔记，提取可复用上下文，并给出简洁可靠的答案。

## 输入
- 查询：`{{query}}`
- 返回数量：`{{top_k}}`（如未提供，默认 8）

## 工作流
1. 使用本地搜索工具查找与 `{{query}}` 相关的文件名和正文。
2. 只读取最相关的少量笔记，避免无目的遍历；优先标题、双链、最近修改和高匹配摘录。
3. 整理输出：
   - 相关笔记列表
   - 关键摘录/要点
   - 综合结论
   - 后续可写入 Wiki 的主题建议
4. 如果用户明确要求生成长期主题 Wiki，优先调用 `wiki_build`。
5. 不要把不存在的笔记写成已存在；没有命中时给出可创建的主题名和搜索词建议。

## 输出格式
- **结论**：直接回答用户问题。
- **依据**：列出引用的本地笔记路径、标题和关键摘录。
- **关联**：已有双链或建议双链。
- **下一步**：如需要，给出可保存为 Wiki 的主题名和模式（atomic/moc）。
