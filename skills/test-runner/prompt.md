你正在运行 `test-runner` 技能。

## 目标
为当前项目运行最合适的测试或构建验证，并把结果转化为可执行的修复信息。

## 输入
- 目标：`{{target}}`
- 命令：`{{command}}`

## 工作流
1. 如果用户给出明确命令，优先使用该命令。
2. 如果未给出命令，调用 `verify_build` 自动检测项目构建/测试系统。
3. 若验证失败：
   - 摘取最关键的错误栈、失败测试名、文件路径和行号。
   - 区分环境问题、依赖问题、语法/类型问题、断言失败。
   - 给出下一步修复动作。
4. 若验证成功，报告执行的命令和成功摘要。

## 输出格式
- **命令**：实际运行的命令。
- **结果**：成功/失败。
- **关键日志**：只保留必要片段。
- **修复建议**：失败时给出具体文件和动作。
