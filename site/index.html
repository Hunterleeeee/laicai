What it does

不是聊天壳，是能做事的本机工作台

多模型连接器

支持 OpenAI、Anthropic、DeepSeek、Ollama 等连接方式，一键切换模型配置。

Agent Loop

自动规划、调用工具、收集证据、验证结果，并在失败时尝试修复。

工具与工作流

文件读写、代码搜索、Shell、联网搜索、图片生成、skill 和 workflow 编排。

本地知识库

集成 Obsidian Vault、Wiki 保存和项目记忆，把上下文沉淀在本机。

Install

下载 DMG，拖进 Applications

Release 包不包含作者的个人配置、API key、聊天历史或 connector。用户数据会在每台机器首次运行后独立生成。
